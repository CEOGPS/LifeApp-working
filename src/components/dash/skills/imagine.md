# Imagine

Use this when making or changing a picture.

## When not to use an image model

Image models garble exact words, invent numbers, and draw charts that do not match the data. If the result needs real text, a real number, a table, or a diagram, build it in the dashboard with HTML, not an image. Use the image tool for photos, illustrations, characters, and scenes.

## Rules

1. If the user wrote the prompt, use it. Otherwise write 2 to 5 sentences: subject, action, setting, style, light.
2. Do not generate a named real person from text alone. Ask for a reference photo. Never make a sexualized or minor likeness.
3. If the picture depends on a current fact, search first and put the verified detail in the prompt.
4. For a repeating character, make one base image, then edit that file. Do not start over each time.
5. If a safety filter blocks it, stop. Do not rephrase the prompt to get around the filter.
6. One scene per prompt. Phone frames are 9:16, banners 16:9, avatars 1:1.
7. Video is a short shot from a still, about 6 seconds, one motion. Do not claim a video exists unless the video tool returned a file.

On this dashboard, Image mode on the Erebus dock is the live image tool. There is no separate image_gen call inside chat. Say that if asked to call one.
